# Day9 Notes
🔹 Array Introduction
Array ek fixed size collection hota hai jisme same data type ke elements store hote hain.

Indexing 0 se start hoti hai.

🔹 Array with Function – Minimum & Maximum Value
INT_MAX aur INT_MIN use karke min/max nikalte hain.

Function getMin() → array ka sabse chhota element return karta hai.

Function getMax() → array ka sabse bada element return karta hai.

🔹 Array Update
Array ke elements ko index ke through update kar sakte ho.

Example:

cpp
arr[2] = 50;  // index 2 par value update
🔹 Linear Search in Array
Ek‑ek element ko check karte hain until key mil jaye.

Agar element match ho jaye → return true.

Agar pura loop chalne ke baad bhi na mile → return false.

🔹 Reverse Array
Start aur End index swap karte hain until dono meet ho jaye.

Example:
Input: {1,4,0,5,-2,15}  
Output: {15,-2,5,0,4,1}
